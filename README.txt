REEFBOUND website
=================

This is the expanded survival-game landing page.

Files:
- index.html
- styles.css
- script.js

GitHub Pages:
1. Upload/replace these three files in the root of your repository.
2. Settings -> Pages -> Deploy from a branch.
3. Branch: main
4. Folder: / (root)
5. Save.

The page includes:
- Survival game overview
- Procedural islands and open ocean
- Rafts and boats
- Crafting
- Modular building
- Combat and loot
- Character creation/customization
- Traders and safe zones
- Factions and infected threats
- Multiplayer/co-op
- Player-created settlements and community vision
- Development roadmap
- Discord/community CTA

Replace the JOIN DISCORD '#' link with your real Discord invite when ready.
